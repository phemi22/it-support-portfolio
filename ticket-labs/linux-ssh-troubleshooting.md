# Lab: Cannot Connect to Linux Server Using SSH

## Priority
P2 - High

## Issue
User cannot connect to a Linux server using SSH.

## First Checks
1. Confirm the user's internet connection is working.
2. Verify the server hostname or IP address is correct.
3. Confirm the SSH username is correct.
4. Ping the server to verify it is reachable.

## Action Taken
1. Tested connectivity using `ping`.
2. Verified the server IP address and hostname.
3. Asked the user to try connecting again with the correct SSH credentials.
4. If the server was unreachable, escalated the issue to the Linux/Server Administrator to check whether the SSH service was running.

## Resolution
User successfully connected to the Linux server after correcting the connection details.
