# Day 18 Lab: Remote Support Using Quick Assist

## Incident Number
INC001801

## Category
Remote Support

## Priority
P3 - Medium

## Issue
The user cannot access Microsoft Teams settings and requests remote assistance.

## First Checks
- Confirm the user has internet access.
- Confirm Quick Assist is installed.
- Ask the user to open Quick Assist.

## Action Taken
- Generated a Quick Assist security code.
- Guided the user to enter the code.
- Requested screen-sharing permission.
- Navigated to Teams Settings and corrected the issue.

## Resolution
User confirmed Microsoft Teams was working correctly after the remote session.

## Ticket Status
Closed
