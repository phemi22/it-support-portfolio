# Linux Basics for IT Support

## What is Linux?

Linux is an open-source operating system widely used for servers, cloud computing, and developer environments.

## Basic Commands

### Show current directory

```bash
pwd
```

### List files

```bash
ls
```

### Change directory

```bash
cd foldername
```

### Create a directory

```bash
mkdir practice
```

### Create a file

```bash
touch notes.txt
```

### View file contents

```bash
cat notes.txt
```

## Networking Commands

```bash
hostname
whoami
ping google.com
ip addr
```

## File Permissions

`chmod` changes file permissions.

Example:

```bash
chmod 755 script.sh
```
