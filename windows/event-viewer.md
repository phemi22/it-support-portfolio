# Windows Event Viewer Notes

## What is Event Viewer?

Event Viewer is a Windows tool that records system, application, and security events.

## Event Types

- Information
- Warning
- Error
- Critical

## Kernel-Power (Event ID 41)

Kernel-Power Event ID 41 indicates that Windows detected an unexpected shutdown or restart.

## Common Causes

- Power failure
- Overheating
- Driver issues
- Hardware problems
