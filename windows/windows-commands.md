# Windows Command Prompt Commands

## Network Commands

```bash
ipconfig
ipconfig /renew
ipconfig /flushdns
ping 8.8.8.8
ping google.com
nslookup google.com
tracert google.com
```

## System Commands

```bash
systeminfo
tasklist
taskkill /IM chrome.exe /F
netstat -an
sfc /scannow
chkdsk
shutdown /r /t 0
```
