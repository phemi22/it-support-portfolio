# Microsoft 365 User Management Lab

## Scenario 1: New Employee Setup

### Steps
1. Create user account.
2. Assign username.
3. Assign Microsoft 365 license.
4. Set temporary password.
5. Enable MFA if required.

## Scenario 2: Outlook Not Receiving Emails

### Troubleshooting
1. Check mailbox storage.
2. Check Outlook sync status.
3. Verify password.
4. Test Outlook Web.
5. Check Credential Manager if password prompts continue.

## Scenario 3: Shared Mailbox Access

### Troubleshooting
1. Confirm mailbox exists.
2. Add user as a mailbox member.
3. Restart Outlook.
4. Verify mailbox appears.
