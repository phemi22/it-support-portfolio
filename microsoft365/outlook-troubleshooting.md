# Lab: Outlook Shows "License Required"

## Priority
P2 - High

## Issue
A new employee can sign in to Windows, but Outlook displays "License Required."

## First Checks
1. Confirm the user account exists in Microsoft 365 Admin Center.
2. Check whether a Microsoft 365 license is assigned to the user.
3. Verify the assigned license includes Outlook (Exchange Online).

## Action Taken
1. Assigned the appropriate Microsoft 365 license to the user.
2. Asked the user to sign out and sign back into Outlook.
3. Verified the license had synchronized successfully.

## Status
User confirmed Outlook opened successfully and email access was restored.
