# DNS, DHCP, IP and MAC Address

## DNS
DNS translates website names (like google.com) into IP addresses.

## DHCP
DHCP automatically assigns an IP address to a device when it connects to a network.

## IP Address
An IP address identifies a device on a network. It can change depending on the network.

## MAC Address
A MAC address is the permanent hardware identifier of a network adapter.

## Useful Commands

```bash
ipconfig
ping 8.8.8.8
nslookup google.com
```
